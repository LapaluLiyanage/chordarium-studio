# Chordarium Studio

VST3 plugin + local companion service that turns a chord sheet and a plain-language brief into a multi-track MIDI arrangement (piano, bass, pad, drums). Sinhala and English chord sheets are first-class. Cubase 15 is the launch DAW.

The AI plans; deterministic rules write the notes.

See `CLAUDE.md` for the full build specification and `CHORDARIUM_STUDIO_UI.md` for the UI spec.

Status: M1 (engine) — code complete, awaiting sample chord sheets and a listening check.
